# Second Wind

Second Wind is a community mod for **PlayStation All-Stars Battle Royale** (US edition) that brings
competitive online play back, on RPCS3 and on PS3.

**Version 1.14 · public beta**

## What you get

- **Ranked 1v1**, with a live ladder at <http://192.241.157.186/>
- **Ranked 2v2** with a friend on the same console
- **Items off** in every Ranked match
- **1.13 balance**: the game's 1.11 balance brought back
- **RPCS3 and PS3 players play together** online
- A clean install on RPCS3: Second Wind makes its own copy of the game update, so your normal setup stays as it is

## Download and install

Downloads and step-by-step instructions for each setup: **<http://192.241.157.186/install>**
(the same guide is in [INSTALL.md](INSTALL.md)).

| You play on | What you need |
| --- | --- |
| RPCS3 on Windows | Second Wind for Windows |
| RPCS3 on Mac | Second Wind for Mac (Apple Silicon) or for Intel Mac |
| PS3 with HEN or custom firmware | webMAN MOD on the PS3, plus Second Wind for PS3 on a PC or Mac |
| Unmodded PS3 | Nothing to download: change the PS3's DNS to play online (without Second Wind's changes) |

You need your own copy of the game (US disc, `BCUS98472`). The US digital edition and European
copies aren't supported yet.

## Beta

1.14 is a beta. Reports we'd most like:

- Ranked 2v2 with four players online
- RPCS3 and PS3 players in different homes playing each other
- Second Wind for PS3 on different consoles and firmware

On RPCS3, run **Make a problem report** from the kit folder and send the file it makes on the Discord.
